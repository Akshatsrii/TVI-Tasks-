## 🔧 How to Run Any Project

```bash
# 1. Clone this repository
git clone https://github.com/Akshatsrii/fullstack-internship-truevalueinfotech.git

# 2. Navigate to a project folder
cd projects/project-01

# ── Frontend ──────────────────────────────
cd client
npm install
npm start           # Runs React app on http://localhost:3000

# ── Backend ───────────────────────────────
cd ../server
npm install
# Add your MongoDB URI & secrets in a .env file
npm run dev         # Runs Node/Express server on http://localhost:5000
```

> ⚠️ MongoDB URI and Firebase credentials are NOT included. Add your own in `.env` / `src/firebase.js`.
